## 二、核心知识点总结（必掌握）

### 1\. 自定义Hook核心定义与规范

- 定义：用JavaScript函数封装React内置Hook（useState/useEffect/useRef等），**只复用状态逻辑，不复用UI**（与组件的核心区别）；

- 强制规范（缺一不可）：
  
    1. 函数名必须以 `use` 开头（如useMountedRef、useLocalChat）；
    
    2. 只能在函数组件或其他自定义Hook内部顶层调用（不能在条件、循环、嵌套函数内）；
    
    3. 内部可使用所有内置Hook，遵循Hook调用规则；
    
    4. 必须有返回值（状态、方法、ref等），供组件调用。
    
- 核心价值：解耦（逻辑与UI分离）、复用（通用逻辑全局复用）、易维护（统一修改、全局生效）、易测试（逻辑独立）。

### 2\. 本次封装3个核心Hook（重点复盘）

|Hook名称|核心功能|核心原理/亮点|使用场景|
|---|---|---|---|
|useMountedRef\.ts|React19严格模式通用挂载锁|用useRef存储挂载状态，useEffect\(\[\]\)只执行一次，标记组件真正挂载，屏蔽假挂载|所有需要规避React19双挂载的场景（如localStorage写入）|
|useChatInput\.ts|输入框受控逻辑抽离|内部维护form状态，提供handleChange（输入变化）、clearInput（清空输入），函数式更新规避闭包|所有输入框场景（聊天、表单等）|
|useLocalChat\.ts（核心）|消息状态\+localStorage持久化|继承Day4稳定逻辑：惰性初始化读存储、ref同步最新值、挂载锁防空值覆盖、函数式更新、异常兜底|聊天页面消息管理，支持刷新不丢失|

### 3\. App\.tsx重构核心思想

- 重构前：App\.tsx包含所有状态、副作用、回调逻辑，代码臃肿、耦合严重；

- 重构后：App\.tsx**只做2件事**—— 调用自定义Hook获取状态/方法、组装UI组件，完全不碰底层业务逻辑；

- 核心优势：代码简洁、易维护，后续修改逻辑只需修改对应Hook，不影响UI组装。

## 三、高频坑点总结（避坑必背）

1. **Hook调用顺序错误**

    - 错误：在if、for、嵌套函数内调用Hook（违背顶层调用规则）；

    - 正确：所有Hook必须在组件/自定义Hook顶层调用，保证每次渲染调用顺序一致。

2. **依赖项缺失导致闭包陷阱**

    - 错误：Hook内部useEffect依赖项不完整（如useLocalChat中遗漏isMounted），导致捕获旧值；

    - 正确：useEffect依赖项必须包含所有用到的状态、方法、ref，确保副作用同步更新。

3. **React19严格模式下Hook重复执行**

    - 问题：开发环境下，Hook内部副作用会因双挂载执行两次，可能导致空值覆盖、重复请求；

    - 解决方案：使用useMountedRef挂载锁、useState惰性初始化，屏蔽假挂载的影响。

4. **Hook返回函数捕获旧闭包**

    - 问题：Hook返回的方法（如sendUserMsg）可能捕获旧状态；

    - 解决方案：状态更新用函数式更新（prev =\&gt; \.\.\.），异步场景用ref\.current获取最新值。

5. **TS类型不完整，出现any**

    - 错误：Hook的状态、事件、返回值未做类型约束，使用any；

    - 正确：严格用interface/type约束所有类型（如InputForm、Message），禁止any。

6. **Hook耦合UI**

    - 错误：自定义Hook内部包含JSX/UI结构；

    - 正确：Hook只封装逻辑，UI相关代码放在组件中。

## 四、企业级最佳实践（必践行）

1. 目录规范：新建src/hooks/目录，所有自定义Hook统一存放，便于管理和复用；

2. 单一职责：一个Hook只做一件事（如useMountedRef只处理挂载标记，不掺杂其他逻辑）；

3. 分类封装：区分通用工具Hook（useMountedRef）和业务Hook（useLocalChat）；

4. 类型约束：严格使用TypeScript，完整约束状态、事件、返回值类型，禁止any；

5. 状态更新：所有setState均使用函数式更新，规避闭包陷阱；

6. 异常兜底：涉及localStorage、JSON解析等操作，必须加try\-catch，防止页面崩溃；

7. 清理副作用：Hook内部有定时器、事件绑定等，必须添加清理函数，避免内存泄漏。

## 五、核心复盘（重中之重）

1. 自定义Hook的核心是「逻辑复用」，与组件「UI\+逻辑复用」形成互补；

2. 3个Hook的封装，彻底实现了聊天页面的逻辑解耦，符合大型项目工程化规范；

3. 继承Day4的localStorage持久化逻辑，确保React19环境下刷新不丢失数据；

4. 掌握Hook的规范和坑点，是后续学习复杂Hook（useDebounce、useThrottle）、状态管理的基础；

5. 本次实战最大收获：学会“抽离通用逻辑”，减少重复代码，提升代码可维护性。
